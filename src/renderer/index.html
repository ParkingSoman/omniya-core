Keyboard help

Reading: Enter explores an equation. MathJax arrows navigate its hierarchy. r replaces the exact focus. a inserts after it. o inserts before it.

Authoring: Type in the document to write. Enter starts a new paragraph; Shift+Enter adds a line break within one. Ctrl+E inserts a Nemeth equation; Ctrl+L inserts LaTeX. Enter commits an unfinished equation, then you are in text again. Escape discards an unfinished equation. Ctrl+T toggles UEB grade on text. Backspace undoes the last Nemeth cell in an open draft. With no pending UEB cells, full cell ⠿ inserts Nemeth (same as Ctrl+E). The UEB word “for” is also ⠿ at the start of a word and will do the same; use Ctrl+E or Insert → Equation (Nemeth) if that collides. The application menu Insert / Format / Help (Alt on Windows; menu bar on Mac) does the same actions.

History: Cmd/Ctrl+Z undoes a submitted replacement. Cmd/Ctrl+Shift+Z redoes it.
