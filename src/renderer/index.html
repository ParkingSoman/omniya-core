Notes

Equation
Write the equation as

Nemeth: type braille cells. LaTeX: type the whole expression. Control E picks Nemeth and Control L picks LaTeX while the field is empty.

Preview

Enter inserts. Escape cancels.

No note open

No note is open. Choose New note to start one.

Export this note

Equations are kept. Choose a file type, then choose where to save it.

Keyboard shortcuts

Writing

New paragraph
Enter
Undo
Ctrl+Z or Cmd+Z
Redo
Ctrl+Y or Cmd+Shift+Z
Select all
Ctrl+A or Cmd+A

Equations

Insert an equation
Alt+= on Windows, Control+= on Mac
Write it as Nemeth or LaTeX
Ctrl+E or Ctrl+L, while the field is empty
Insert it
Enter
Cancel
Escape

Reading and editing an equation

Move past it
Arrow keys. The first press selects it. The next moves on.
Delete it
Backspace twice. The first press selects it.
Read it by parts
Select it, press Enter, then use the arrow keys.
Replace the part you are on
r
Insert after it, or before it
a or o
Return to the note
Escape

Finding and sharing

Find in the note
Ctrl+F or Cmd+F
Next or previous match
Enter or Shift+Enter, in the find box
Close the find box
Escape. The match stays selected.
Print
Ctrl+P or Cmd+P
New note
Ctrl+N or Cmd+N

The Insert and Help menus run the same actions (Alt on Windows, the menu bar on Mac). If braille input misbehaves, choose Help, then Copy braille input diagnostics, and paste it into your report. This build: unknown.
