Authoring method

Nemeth builds the equation one cell at a time. LaTeX accepts the whole expression.

Enter inserts the equation. Escape cancels. Ctrl+E picks Nemeth and Ctrl+L picks LaTeX while the field is empty.

Keyboard help

Writing: Type in the document. Enter starts a new paragraph. Ctrl+Z (Cmd+Z on Mac) undoes. Ctrl+Y (Cmd+Shift+Z on Mac) redoes. Undo covers typing and equations in one history.

Equations: Alt+= on Windows, or Control+= on Mac, inserts an equation at the caret. Type it as Nemeth braille or LaTeX. Enter inserts it. Escape cancels. While the field is empty, Ctrl+E picks Nemeth and Ctrl+L picks LaTeX. The Nemeth field takes braille cells only. A braille display works whether it sends cells or the plain text a computer-braille table produces. The status line says which reading the app used.

Reading an equation: Arrow keys move past an equation as one unit. The first Backspace next to it selects it. A second Backspace deletes it. With an equation selected, Enter reads it by parts. The arrow keys then move through its structure. r replaces the part you are on. a inserts after it. o inserts before it. Escape returns to the document.

Braille: Ctrl+T (Cmd+T on Mac) toggles UEB grade. The Insert, Format and Help menus (Alt on Windows; menu bar on Mac) run the same actions.

Build: unknown. If braille input misbehaves, Help → Copy braille input diagnostics puts this and the last few keystrokes on the clipboard for a bug report.
